Genealogy Map v18.7 — Icon Package

What this package includes
- apple-touch-icon.png  (the important one for iPhone home-screen shortcuts)
- icon-180.png
- icon-192.png
- icon-512.png
- icon-1024.png
- icon-globe.svg
- favicon-16.png
- favicon-32.png
- favicon.ico
- site.webmanifest
- browserconfig.xml
- head-snippet-v18.7.html
- index.html (preview/demo page)

What to do
1. Upload these files to the same folder as your real site index.html.
2. Copy the contents of head-snippet-v18.7.html into the <head> of your real index.html.
3. Deploy/refresh your site.
4. On iPhone, delete the old home-screen shortcut and add it again if the old icon sticks around.

Notes
- This package rebuilds the icon setup from scratch.
- The included index.html is only a preview/demo file, not your actual genealogy app.
